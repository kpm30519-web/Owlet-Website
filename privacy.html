Owlet Recipe Saver Privacy Policy

Effective Date: September 21, 2026

Owlet Recipe Saver (“Owlet”) is an independent browser extension developed by Keniem. Owlet captures structured recipe information from webpages when the user explicitly chooses to do so and allows the user to review, edit, print, and export that information.

Owlet does not operate a server that receives or stores users’ recipe information. KitchenOwl is an optional server-storage destination selected by the user. Owlet is not affiliated with, endorsed by, or sponsored by KitchenOwl.

Information Owlet Handles

Depending on the features the user chooses to use, Owlet may handle:

  • KitchenOwl username or email entered by the user
  • Authentication access and refresh tokens returned by the selected KitchenOwl server
  • Recipe title, ingredients, instructions, preparation and cooking times, servings, and user-entered tags
  • Recipe images
  • Selected KitchenOwl household
  • Recipe source information, including the source URL
  • Import/export files selected by the user
  • Limited diagnostic information

Owlet reads recipe information only after the user explicitly selects the recipe-reading function. Owlet does not continuously monitor browsing activity, automatically inspect webpages, or collect information from webpages simply because the user visits them.

The source URL is retained as recipe metadata only when the user chooses to save or export a recipe. Before being used, the URL is sanitized to remove credentials, query strings, and fragments.

Recipe images may be loaded during recipe review and may appear in printouts. When the user chooses to save a recipe containing an image to KitchenOwl, Owlet downloads the image and sends it to the KitchenOwl server selected by the user. Owlet does not permanently store image bytes.

How Information Is Used and Shared

Owlet uses information solely to provide its recipe capture, review, editing, printing, exporting, and optional KitchenOwl-saving functions.

When the user chooses to save a recipe to KitchenOwl, recipe information and, when applicable, the recipe image are transmitted directly to the KitchenOwl server selected by the user.

Authentication credentials and tokens are used solely to authenticate the user's connection to the selected KitchenOwl server.

Keniem does not receive, store, sell, or otherwise process users’ recipe information or recipe images through an Owlet-operated server.

Owlet does not:

  • Sell user information
  • Use user information for advertising or marketing
  • Use browsing history for advertising or profiling
  • Use recipe information to create personalized recommendations
  • Operate analytics or tracking services
  • Automatically monitor browsing activity
  • Automatically inspect webpages as the user browses

KitchenOwl servers, including self-hosted servers, are controlled by their respective operators. Their privacy, security, and data-retention practices are separate from Owlet’s and are governed by the policies of the applicable server operator.

Local Storage and Security

Owlet stores certain information locally in the browser extension’s storage, including:

  • Selected KitchenOwl server address
  • KitchenOwl username
  • Print-option preferences
  • Interface visibility, font, and theme preferences
  • Print handoff data
  • Limited diagnostic information

Owlet does not store the KitchenOwl password in persistent extension storage.

Authentication access and refresh tokens are maintained in browser session storage rather than persistent extension storage and are intended to disappear when the browser/extension session ends.

Disconnecting from KitchenOwl or a failed connection removes the session credentials maintained by Owlet.

Owlet may request access to the webpage currently being viewed when the user explicitly chooses to read a recipe. This permission is used to extract recipe information from the webpage.

Owlet may also request access to the selected KitchenOwl server when the user explicitly chooses to connect KitchenOwl.

Owlet does not use these permissions to automatically monitor or inspect webpages as the user browses.

Users can manage or revoke extension permissions through Firefox’s extension/add-on settings.

Diagnostic Information

Owlet provides an optional diagnostic log that the user may download from the extension menu. The diagnostic log is designed to contain limited operational information such as timestamps, operation names, counts, response status, data format, and generic error categories.

The diagnostic log is not intended to contain passwords, authentication tokens, authorization headers, cookies, session identifiers, recipe contents, recipe titles, source URLs, or image URLs.

Diagnostic information is maintained locally by the extension unless the user explicitly chooses to download the diagnostic log.

The user can clear diagnostic information by removing the extension’s stored data or uninstalling Owlet.

Firefox Extension Permissions

Owlet uses Firefox extension permissions to provide its functionality.

  • activeTab — allows Owlet to access the active webpage following an explicit user action.
  • scripting — allows Owlet to extract recipe information from the selected webpage.
  • storage — allows Owlet to store the limited local information described in this policy.
  • sidebar functionality — provides the Owlet user interface in Firefox’s sidebar.

Owlet may request optional access to HTTP and HTTPS webpages when the user explicitly chooses to read a recipe.

Owlet may also request access to a KitchenOwl server selected by the user when the user explicitly chooses to connect that service.

These permissions support user-initiated recipe capture and saving. They do not cause Owlet to automatically monitor, track, or inspect webpages as the user browses.

Data Collection

Owlet does not operate an analytics, advertising, tracking, or telemetry service.

Owlet does not transmit personal information, browsing history, or recipe information to Keniem-operated servers.

Information is transmitted to a third-party or self-hosted KitchenOwl server only when the user explicitly chooses to connect to that server and performs an operation requiring the transmission of information.
