PRINT & EXPORT

Print, Import & Export Recipes

Owlet isn't limited to one destination. You can print recipes or work with recipe files locally.

Create a clean, printable version of a recipe.

Not every recipe needs to live in a recipe service. Sometimes you just want a clean copy for the kitchen, or you want to keep a recipe file for your own records.

Print a clean recipe

Owlet provides a print-friendly view so you can create a recipe you can take into the kitchen without all the surrounding webpage clutter.

Import and export recipe data for local use.

Import and export locally

Owlet also supports working with recipe data locally. This can be useful when moving recipes between systems, keeping a backup, or maintaining a copy outside a particular online service.

That flexibility is part of Owlet's basic philosophy: capture the recipe you choose, review it, and then decide where you want the recipe to go.
