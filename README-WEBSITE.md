# Owlet Website

Static 2-page website for GitHub Pages.

## Pages
- `index.html` — product landing page
- `privacy.html` — Firefox-compatible privacy policy

## Before publishing
Replace the three `href="#"` browser store links in `index.html` with the actual Firefox, Chrome, and Edge store URLs after the listings are live.

## GitHub Pages
Upload this folder to a GitHub repository and enable GitHub Pages. Then configure the custom domain `owlet.keniem.com` in the repository's Pages settings and create the DNS record requested by GitHub.
